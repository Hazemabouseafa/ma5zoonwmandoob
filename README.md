# نظام "المراعي" لإدارة وتوزيع السلع سريعة التلف (Al-Marai B2B Van Sales & Distribution)
### تحت إدارة: أ/ محمود عبد الله

تطبيق سحابي وإنتاجي متكامل باللغة العربية مع دعم كامل لاتجاه اليمين لليسار (`dir="rtl"`)، مصمم خصيصاً لتوزيع منتجات المراعي والسلع سريعة التلف (الألبان: صلاحية 1 يوم، العصائر: 7-10 أيام)، مع تتبع صارم لنظام الوارد أولاً يصرف أولاً (FIFO)، ومزامنة حية بين الإدارة والمناديب، وتسوية جرد ونقدية نهاية اليوم لمنع أي عجز أو تلفيات.

**مستودع المشروع على GitHub**: [https://github.com/Hazemabouseafa/ma5zoonwmandoob](https://github.com/Hazemabouseafa/ma5zoonwmandoob)

## الميزات والوحدات الرئيسية (Core Features)

### 1. إدارة الحساب والأمان:
- **تغيير كلمة مرور المدير العام**: خاصية للمدير العام لتغيير كلمة المرور الخاصة بحسابه في أي وقت من لوحة التحكم مع التحقق من كلمة المرور السابقة.
- **توقيت الفواتير بالدقيقة**: تسجيل وإظهار وقت وتاريخ إصدار الفواتير بالدقيقة في لوحة تحكم الإدارة، شاشات المندوب، رسائل الواتساب، والإيصالات الحرارية.
- **مزامنة حية فائقة السرعة مع تقليل استهلاك الباقة (Ultra-low Vercel Transfer)**: نظام ذكي للتزامن المباشر بين المندوب والمدير يفحص التحديثات بحزم بيانات خفيفة للغاية (أقل من 20 بايت) ويتوقف تلقائياً عند تصغير أو قفل الشاشة لتوفير باقة الـ Fast Origin Transfer بنسبة 95%.

### 2. إدارة المنافذ والسوبرماركتات (Outlets & Supermarkets):
- **إضافة وتعديل المنافذ**: إضافة أي منفذ أو سوبرماركت باسمه (الاسم هو الحقل الإجباري والأساسي)، مع إمكانية إضافة العنوان ورقم الهاتف والمديونية اختيارياً.
- **كشف الحساب والمديونيات**: عرض فوري لأرصدة مديونيات كل منفذ والتحصيلات المسددة وتاريخ التعاملات.

### 3. فواتير المناديب مع نظام الخصومات (Rep POS & Discounts):
- **إصدار فواتير ذكية للمناديب**: واجهة شاشات لمس سريعة ومخصصة للهاتف المحمول بأزرار كبيرة `+` و `-`.
- **منح الخصومات**: إمكانية إدخال قيمة خصم نقدي (ج.م) على الفاتورة، وحساب فوري للمجموع قبل الخصم، قيمة الخصم، والصافي المطلوب.
- **مشاركة وطباعة فورية**: توليد رسالة واتساب (WhatsApp) تلقائية تتضمن تفاصيل الخصم واسم المحل والمندوب، بالإضافة لطباعة إيصال حراري فوري (Thermal POS Receipt).

### 4. شفافية كاملة للإدارة على فواتير المناديب (Detailed Invoices Audit):
- **مراقبة فواتير كل مندوب**: شاشة مخصصة للمدير العام تتيح فلترة ومعرفة كل مندوب طلع فواتير لمين، الأصناف والكميات بالكامل، طريقة السداد (نقدي / آجل)، ونسبة وقيمة الخصم الممنوح مميزة بشارات واضحة.

### 5. إدارة عهدة السيارات والمخزون الصارم (FIFO & Inventory):
- **صلاحيات حرجة (FIFO Alerts)**: تنبيهات فورية للألبان المهددة بانتهاء الصلاحية خلال 24 ساعة، والعصائر خلال 48 ساعة.
- **تحويل بضاعة للسيارات (Dispatch)**: تحويل كميات من المستودع لسيارة أي مندوب بضغطة زر وبمعاملة ذرية تمنع أي رصيد سالب.
- **تسوية وجرد نهاية اليوم (Reconciliation)**: مطابقة آلية للكاش المتوقع تسليمه من المندوب مقابل الكاش الفعلي، وجرد البضاعة المتبقية وكشف أي عجز في الأموال أو المخزون فورياً.

### 6. إدارة تصنيفات المنتجات ديناميكياً (Dynamic Product Categories):
- **إضافة وإلغاء التصنيفات**: إمكانية إضافة تصنيفات منتجات جديدة أو حذف التصنيفات القائمة بمرونة تامة من شاشة المخزون (`/admin/inventory`).
- **تحديد العمر الافتراضي**: ضبط الصلاحية الافتراضية بالأيام لكل تصنيف لحساب تواريخ الصلاحية والتنبيهات تلقائياً.
- **حماية تكامل البيانات**: منع حذف أي تصنيف مرتبط بأصناف أو تشغيلات موجودة في المستودع.
- **فلاتر ديناميكية**: تحديث فوري لخيارات الفلترة وعرض عدد التشغيلات في كل تصنيف.

### 7. نظام نظيف تماماً وخالي من البيانات الوهمية (Zero Fake Data):
- تم حذف جميع البيانات التجريبية؛ يبدأ النظام بقاعدة بيانات نظيفة 100% ليقوم المدير بإضافة منتجاته ومنافذه ومخزونه الحقيقي.

## النشر السحابي على Vercel وربط Neon PostgreSQL

1. **إنشاء قاعدة بيانات Neon**:
   - أنشئ مشروعاً جديداً على [Neon](https://neon.tech).
   - انسخ رابط الاتصال وضع متغير البيئة `DATABASE_URL` في Vercel.

2. **متغيرات البيئة على Vercel (Environment Variables)**:
   ```env
   DATABASE_URL="postgresql://neondb_owner:YOUR_PASSWORD@ep-xyz.us-east-2.aws.neon.tech/neondb?sslmode=require"
   JWT_SECRET="al-marai-super-secret-jwt-key-2026-production"
   NODE_ENV="production"
   ```

3. **تطبيق الجداول وبذر المدير العام في Neon**:
   ```bash
   # دفع الجداول لقاعدة البيانات السحابية
   npx prisma db push

   # بذر حساب المدير العام
   npm run db:seed
   ```

4. **التشغيل محلياً**:
   ```bash
   npm install
   npm run build
   npm run start
   ```
